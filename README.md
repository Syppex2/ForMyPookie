# 🦋 The Butterfly Altar

A Shinobu-themed (Kimetsu no Yaiba) altar website for my favorite person.

## Christmas mode
Turns on by itself from December 1 to 26: snow, lights, advent notes, Jingle Bells,
Shinobu's Christmas art, Maxwell's Santa hat and a present that opens on December 25.
Preview it any time:
- `index.html?christmas=1` (pretends it's December 7)
- `index.html?christmas=25` (Christmas Day, the present opens)
- `index.html?christmas=0` (forces it off)
The texts are at the top of `christmas.js`.
